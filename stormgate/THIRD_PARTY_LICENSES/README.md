# Third-party license texts

Release runtimes carry the full license text of every shipped component in
`<runtime>/licenses/`, copied from the pinned upstream sources by
`scripts/package.sh` (e.g. `wine-COPYING.LIB`, `moltenvk-LICENSE`).

They are not duplicated in Git to avoid drifting from upstream. See
[`../LICENSES.md`](../LICENSES.md) for the summary table.

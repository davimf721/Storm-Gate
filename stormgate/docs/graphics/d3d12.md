# D3D12 (experimental)

```text
D3D12 → VKD3D-Proton → Vulkan → MoltenVK (patched) → Metal
```

The [VKD3D-Proton-MacOS](https://github.com/metalsharp/VKD3D-Proton-MacOS)
project demonstrates this path on Apple Silicon. Storm Gate treats it as a
**reference**, not a dependency: its changes are reviewed and imported as
individual patches with metadata into `patches/vkd3d-proton` and
`patches/moltenvk`, and only kept when reproduced on our own hardware.

| Plan directory | Where it lives here |
|---|---|
| `graphics/d3d12/vkd3d` | `build/sources/vkd3d-proton` (pinned in `manifests/`) |
| `graphics/d3d12/moltenvk` | `build/sources/moltenvk` |
| `graphics/d3d12/patches` | `patches/vkd3d-proton`, `patches/moltenvk` |
| `graphics/d3d12/probes` | `tests/windows/d3d12-probe` (issue #18) |
| `graphics/d3d12/tests` | `tests/windows/d3d12-triangle` |

## Order of work

1. **Feature probe** — create a device, print feature levels, resource
   binding tier, shader model, wave ops; exit 0.
2. **Triangle** — offscreen render + pixel check, like `d3d11-triangle`.
3. **Small game.**
4. **AAA game.** Never start here.

Every failure becomes a minimal test ("resource barrier test #17 fails"),
never "game X is black".
